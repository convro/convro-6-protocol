# C6P Sessions Test Vectors

**Version:** 1.0
**Status:** PRODUCTION / NORMATIVE
**Purpose:** Deterministic test vectors for session and ratchet operations

---

## Overview

This directory contains test vectors for C6P v1 session operations:
- **Ratchet key derivation** (chain key advancement, message key derivation)
- **Send/receive flows** (encryption, decryption, counter management)
- **Replay detection** (consumed set management)
- **Skip-window validation** (out-of-order acceptance)
- **Session lifecycle** (state persistence, recovery)

---

All vectors follow this schema:

```json
  "version": "1.0",

  "generated_at": "2024-01-01T00:00:00Z",
  "description": "Brief description of test scenarios",
  "vectors": [
    {
      "case_id": "SEND_001",
      "description": "First message send with counter=0",
      "inputs": { ... },
      "intermediate": { ... },
      "outputs": { ... }
    }
  ]
}
```

## Files

### v1/ (C6P v1 Vectors)

- **`ratchet_send_vectors.json`**: Send flow test vectors (counter increment, CK advancement)
- **`ratchet_receive_vectors.json`**: Receive flow test vectors (in-order, out-of-order, replay)
- **`skip_window_vectors.json`**: Skip-window validation scenarios
- **`session_persistence_vectors.json`**: State save/load, crash recovery
- **`negative_vectors.json`**: Error conditions (replay, skip-window exceeded, decryption failures)

---

## Generation

Test vectors are generated by the centralized test vector generator:

```bash
cd rust
cargo run --package c6p-test-vectors --bin c6p-gen-vectors -- --output test-vectors --force --verbose
```

**Output Location:** `rust/test-vectors/Sessions/test-vectors/v1/`

**Determinism:** All vectors use fixed seeds for reproducibility across implementations. Test vectors use Timon (initiator) and Peter (responder) as example participants.

## Usage

### Integration with Test Suites

**Rust:**
```rust
#[test]
fn test_ratchet_send_vectors() {
    let vectors: TestVectors = serde_json::from_str(include_str!("../test-vectors/v1/ratchet_send_vectors.json"))?;
    for vector in vectors.vectors {
        let envelope = send_message(vector.inputs)?;
        assert_eq!(envelope.counter, vector.outputs.counter);
        assert_eq!(hex::encode(envelope.ciphertext), vector.outputs.ciphertext_hex);
    }
}
```

**Swift:**
```swift
func testRatchetSendVectors() throws {
    let url = Bundle.module.url(forResource: "ratchet_send_vectors", withExtension: "json")!
    let vectors = try JSONDecoder().decode(TestVectors.self, from: Data(contentsOf: url))
    for vector in vectors.vectors {
        let envelope = try sendMessage(vector.inputs)
        XCTAssertEqual(envelope.counter, vector.outputs.counter)
        XCTAssertEqual(envelope.ciphertext.hexString, vector.outputs.ciphertextHex)
    }
}
```

## Validation

All vectors MUST pass the following checks:
- **Determinism**: Same inputs → same outputs (no randomness)
- **Consistency**: Outputs match spec-defined algorithms
- **Completeness**: Cover all normative scenarios from `sessions-test-matrix.md`
